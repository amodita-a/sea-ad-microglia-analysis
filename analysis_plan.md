# Analysis Plan
## Project
Microglial Immune Activation Across Alzheimer's Disease Pathology
## Primary Research Question
Are microglial interferon-response and antigen-presentation programs different between donors with low/no Alzheimer's disease pathology and donors with high Alzheimer's disease pathology?
## Dataset
The project will use publicly available single-nucleus RNA-sequencing data from SEA-AD.
## Cell Type of Interest
Microglia.
## Planned Unit of Analysis
Results will ultimately be summarized at the donor level rather than treating every individual nucleus as an independent person.
## Planned Outcomes
The project will examine:

1. Interferon-associated immune activity.
2. Antigen-presentation-associated activity.

## Planned Outputs

- Data summary
- Donor-level analysis table
- Immune pathway visualizations
- Reproducible Python notebooks
- Written interpretation
- Limitations
## Current Status
Work in progress. The computational methods and exact analytical workflow will be refined as I develop the required skills.
