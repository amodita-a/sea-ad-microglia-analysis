# Microglial Immune Activation Across Alzheimer's Disease Pathology

## About This Project

This repository documents a work-in-progress educational reanalysis of publicly available Alzheimer's disease single-nucleus RNA-sequencing data.

I am undertaking this project to develop foundational skills in Python, computational biology, and neurogenomics while exploring inflammatory processes involving microglia in Alzheimer's disease.

## Research Question

Are microglial interferon-response and antigen-presentation pathways different across Alzheimer's disease neuropathology groups?

## Dataset

This project will use publicly available data from the Seattle Alzheimer's Disease Brain Cell Atlas (SEA-AD).

The analysis will use existing cell-type annotations and will focus primarily on microglia.

## Planned Analysis

1. Learn foundational Python and data-analysis skills.
2. Explore the structure and metadata of the SEA-AD dataset.
3. Identify previously annotated microglial nuclei.
4. Examine selected immune and inflammatory gene programs.
5. Summarize results at the donor level.
6. Create reproducible visualizations of the findings.

## Current Status

**Work in progress: August 2026**

I am currently learning the computational methods required to complete this analysis.

## Disclaimer

This is an independent educational reanalysis of publicly available research data. It has not undergone peer review and is not intended to establish clinical or causal conclusions.
